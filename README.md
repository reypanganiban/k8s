# k8s

Personal sandbox for learning Kubernetes. Small manifests, short notes, nothing production.

## Layout

- `manifests/` — YAML I write while learning, grouped by topic
- `notes/` — short bullet notes per concept

Both folders get created as I add content.

## Getting started

Local cluster setup goes here once I pick a tool (kind, minikube, Docker Desktop).
